# Zeeshan Mushtaq — Portfolio

Backend Engineer | PHP & Laravel — portfolio built with **Vite + React + TypeScript**.
Dark theme only, responsive (desktop wide multi-column, mobile stacked).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build for production

```bash
npm run build
npm run preview
```

The production output is in `dist/`.
